# Center ponovne uporabe (CPU) – spletna stran

Šolski projekt pri predmetu RMA. Spletna stran predstavi [Center ponovne uporabe](https://www.cpu-reuse.com/), slovensko socialno podjetje, ki zbira še uporabne izdelke, jih obnovi in ponovno proda.

## Strani

| Datoteka | Vsebina |
|---|---|
| `index.html` | predstavitev, pozdrav z uro (JavaScript) |
| `dejavnost.html` | kako deluje center, Repair Café, kartice terminov iz polja objektov (JavaScript) |
| `informacije.html` | tabela centrov in delovnega časa, kalkulator prihranka (JavaScript) |
| `kontakt.html` | kontaktni podatki in obrazec |

## Zgradba projekta

- `css/` – skupni slog `style.css` in slog za vsako podstran
- `js/` – `pozdrav.js`, `termini.js`, `kalkulator.js`
- `slike/` – fotografije (Wikimedia Commons, CC BY-SA 4.0) in dekorativno ločilo
- `proces.md` – potek dela pri vseh vajah

## Zagon

Odpri `index.html` v brskalniku. Strežnik ni potreben.
